# Aurora Landing Page

A responsive, single-page website with a scenic background, bright accent colors, and translucent bordered cards. Built with plain HTML and an external CSS stylesheet.

## Features

- Full-width scenic background with a dark overlay for readable text
- Responsive layout for desktop, tablet, and mobile
- Navigation links that jump to each section
- Translucent panels with subtle borders and shadows
- Keyboard focus styles and reduced-motion support
- No build tools or JavaScript required
